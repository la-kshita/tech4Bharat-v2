This repository is public for research showcase and review. No blanket licence is granted for its contents. Individual papers, datasets, code, and model weights retain their respective terms; the fact that a file is publicly reachable does not establish permission to reuse it commercially or redistribute it.

Dataset images and model bundles are not included. Review each provider's current licence and dataset-specific terms before downloading or using any material. The DeepPCB repository, for example, distinguishes its research-use dataset terms from repository metadata.

The project experiment notes, reports, and selected metadata are preserved as research records. Contact the project authors for reuse permission unless a file's own licence clearly says otherwise.
