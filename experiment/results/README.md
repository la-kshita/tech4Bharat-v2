# Result records

The JSON files record the experiment's calibration, frozen test results, synthetic transforms, split/leakage checks, browser parity, and environment summary. Use [summary.json](summary.json) for aggregate outcomes and the [protocol](../PROTOCOL.md) for metric definitions.

Brightness and blur files are transformed copies of the same test images, not independent factory examples. Browser parity is a technical preprocessing/inference comparison on one computer, not a phone or production acceptance test. Scores are not probabilities.
